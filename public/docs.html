Example PHP Code

<?php $apiUrl = 'https://your-domain/api/v2'; $apiKey = 'YOUR_API_KEY'; $data = [ 'key' => $apiKey, 'action' => 'add', 'service' => 100001, 'link' => 'https://t.me/example', 'quantity' => 1000, ]; $ch = curl_init($apiUrl); curl_setopt($ch, CURLOPT_POST, 1); curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query($data)); curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1); $response = curl_exec($ch); curl_close($ch); $result = json_decode($response, true); print_r($result); // => ["order" => 23501]

Errors

All errors are returned as {"error": "message"} with HTTP 200, matching common SMM-panel API conventions so existing reseller scripts work without modification.
